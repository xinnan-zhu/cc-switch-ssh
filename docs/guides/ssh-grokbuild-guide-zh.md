# Grok Build 远端切换

在 Grok Build 页面打开「远端 SSH 配置」，选择 SSH Host 或手动连接服务器，即可读取远端配置、同步为本地供应商，或将本地供应商写入远端。

直接切换只修改 `~/.grok/config.toml` 的默认模型和供应商模型表，保留远端 MCP、界面设置及其他模型表。已识别的旧供应商表会清理；无法确认归属的模型表会保留。切回官方条目使用远端自身的 xAI 登录，不复制本机登录凭据。使用 `env_key` 的供应商需要在远端自行设置对应环境变量。

写入后重新打开 Grok Build。停止进程操作会中断当前 SSH 用户的 Grok CLI 会话，不会自动重新启动。写入没有远端自动备份，也不支持远端自定义配置目录。

也可以启用本机网关：通过免密 SSH 反向隧道，将远端 Grok 请求发到本机 `/grokbuild/v1` 路由。网关可固定第三方供应商或跟随本机路由，本机和 CC Switch 需要保持在线。首次启用后重新打开远端 Grok，后续供应商切换由网关处理。官方订阅登录不支持网关转发。

退出网关时会写回所选直连供应商，并清理携带本机网关 token 的旧模型表。配置预览会隐藏 TOML 中的 API Key 和 token。
