## CC Switch SSH v4.0.1-ssh.1

基于官方 **CC Switch 4.0.1**，保留 SSH 远端供应商管理与反向隧道网关，并完成新版界面、配置写入和聚合模式的适配。

### 本次更新

- 合入官方 4.0.1：新版侧栏和界面、直连 / 路由 / 聚合模式、重建的用量面板与会话阅读器，以及官方 4.0.1 的修复。
- 在 Claude Code、Codex、Gemini CLI 页头提供远端配置入口，保留网关主机状态和跳转管理功能。
- 保留 SSH 配置推送、远端配置导入、进程重启和反向隧道；采用新版 Claude / Codex 配置接口，继续保留远端自己的设置、登录及 Codex 供应商 ID。
- 固定远端供应商时禁用本地故障转移，并阻止聚合模型绕过固定路由。跟随本地时保留聚合模型选择；依赖本机官方登录的供应商仍不能通过远端网关使用。
- 本地退出路由时，远端正在使用的共享代理继续运行。
- 修复远端网关请求在新版用量详情、速度统计中的来源识别。
- 云同步保留本机 SSH 网关记录与令牌，避免同步官方数据库后丢失隧道配置；完整备份仍包含这些数据。

### 下载

- **macOS（Universal，Apple Silicon / Intel）**：`CC-Switch-v4.0.1-ssh.1-macOS.dmg` 或 `.zip`
- **Windows（x86_64）**：`CC-Switch-v4.0.1-ssh.1-Windows.msi` 或 `-Windows-Portable.zip`
- **Linux（x86_64）**：`CC-Switch-v4.0.1-ssh.1-Linux-x86_64.AppImage`、`.deb` 或 `.rpm`

`.tar.gz`、`.sig` 和 `latest.json` 用于应用内自动更新，无需手动下载。自动更新继续跟随本仓库，不会被官方版本覆盖。

### 升级与安装

- 大版本升级前，建议备份 `~/.cc-switch/` 和客户端配置。数据库 schema 仍为 19，但新版会更新客户端文件与设备状态。官方说明见 [4.0 升级须知](https://github.com/farion1231/cc-switch/blob/v4.0.1/docs/release-notes/v4.0.0-zh.md#升级须知)。
- macOS 包采用临时签名，没有 Apple 开发者证书公证。如系统提示“已损坏”，可执行 `xattr -cr "/Applications/CC Switch.app"`。
- Windows 包未做代码签名，首次安装可能显示 SmartScreen 提示。
