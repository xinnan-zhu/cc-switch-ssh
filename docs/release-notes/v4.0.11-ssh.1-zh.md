# CC Switch SSH v4.0.11-ssh.1

合并官方稳定版 **4.0.11**，并增加 SSH 远端会话用量统计。

## 远端用量

- 在远端页面连接服务器后，可以为该主机开启每 5 分钟同步，或点击「立即同步」。自动同步需要 SSH 密钥登录；密码连接可以手动同步，密码不会保存。
- 支持 Claude Code、Codex、Gemini CLI、Grok Build 的会话日志，包括 Claude 子代理与 Codex 归档。默认导入最近 30 天，也可以选择全部历史；每个应用可填写多个日志目录，适用于自定义 CODEX_HOME、多个账号或安装目录。
- 采集通过 SSH 临时执行 Python，只读取会话文件，不写远端文件，也不安装常驻服务。只传输时间、模型、会话／消息标识和 token 数等用量元数据，不传输对话、工具内容或认证文件。远端需要 Python 3；Codex 压缩归档还需要服务器已有 `zstd` 命令或 Python `zstandard` 模块，缺失时会提示，其他日志仍可同步。
- 持久化每个文件的读取断点、Codex 累计计数与消息去重账本。重试、日志截断、改写、移动和归档不会重复累计已经导入的记录；不完整的末行留待下次读取。同步有时间和容量上限，较大的历史库可能需要多轮完成。
- 用量面板新增「本机和全部远端」「仅本机」「指定主机」筛选，统一作用于 token、缓存命中率、费用、趋势和明细。费用按模型定价估算；没有计时的会话记录不显示速率。远端网关带精确计时的请求纳入速度统计。
- 网关与会话采集按主机、应用区分。有上游消息 ID 时精确去重；缺少 ID 的日志使用明确的网关记账时段：该主机和应用启用网关期间，由网关负责用量，会话采集跳过该时段，避免重复记账。这期间绕过网关的同应用用量也不会由会话采集补入；如果需要统计直接连接，请先关闭该应用的网关模式。
- 远端同步设置和断点属于本机数据，WebDAV／S3 配置同步会保留它们，不复制到其他设备。

## 官方更新

合并 4.0.9、4.0.10、4.0.11 的稳定版更新，包括应用卸载、所有应用默认查询套餐额度、Codex 分叉和子代理用量修复、Windows 更新后 npm 路径修复等。完整说明见[官方 4.0.11 发布说明](https://github.com/farion1231/cc-switch/blob/v4.0.11/docs/release-notes/v4.0.11-zh.md)。现有 SSH 切换、Codex 认证修复、网关和远端 CLI 更新功能保留。

## 升级说明

数据库升级到 schema 21，为日汇总保留统计来源，升级前自动备份。旧版本已经汇总并清理的明细没有保留主机来源，无法准确还原：这些总量保留在「本机和全部远端」，也可以通过「旧版历史汇总（来源未知）」单独查看；不归入本机或任何指定主机。仍保留的旧版明细可以正常按来源筛选。

应用内更新继续使用本仓库的更新地址和签名配置。提供 macOS Universal、Windows x86_64、Linux x86_64 安装包；三平台构建成功后自动发布并核验发布资产。

## 验证

前端全量 2670 项、远端设置卡片新增 2 项、完整 Rust 3902 项测试通过；Python 采集器 10 项测试通过。TypeScript、生产前端构建、格式检查和 Clippy 通过，真实 SSH 主机重复同步无新增记录。
