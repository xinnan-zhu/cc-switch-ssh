# CC Switch SSH v4.0.13-ssh.1

合并官方稳定版 **4.0.12** 和 **4.0.13**，修复远端用量同步总是超时，并整理远端页面布局。

## 修复

- **远端用量同步不再总是超时。** 之前写完采集脚本后没有真正关闭 SSH 的标准输入，远端 `python3` 一直等不到脚本结束，每次都在 75 秒后报「远端采集超时，断点保留，可重试」。现在脚本发送完毕即关闭输入，同步通常几秒完成。已有断点不受影响，升级后点「立即同步」即可。
- **远端没有 Python 3 时改用 Node.js 采集。** 先尝试 `python3`，找不到时自动在登录 shell 的 PATH 下运行 `node`，nvm、fnm、volta 等用户级安装也能找到。两种采集器读同一份断点、输出一致，可以在两者之间切换而不重复计数。Node 版读取 Codex 压缩归档需要 Node.js 内置 zstd 支持或服务器上的 `zstd` 命令。

## 改进

- **远端页面分成「供应商」和「CLI 与用量」两个页签。** 远端 CLI 版本和远端用量统计移到「CLI 与用量」，切换远端供应商不再被挤到页面下方。
- **远端页面增加返回按钮。** 页头左侧新增返回箭头，回到供应商列表；进入远端页面后不再显示「远端配置」按钮。

## 官方更新

合并 4.0.12、4.0.13 的稳定版更新：Claude Desktop 直连／路由／聚合三种模式、Codex 自动审批模型、应用页安装／升级／卸载与冲突检测、本地模型分组、GPT 窗口封顶 272K 等。完整说明见[官方 4.0.13 发布说明](https://github.com/farion1231/cc-switch/blob/v4.0.13/docs/release-notes/v4.0.13-zh.md)和[官方 4.0.12 发布说明](https://github.com/farion1231/cc-switch/blob/v4.0.12/docs/release-notes/v4.0.12-zh.md)。现有 SSH 切换、远端网关、远端 CLI 更新和远端用量功能保留。

## 升级说明

应用内更新继续使用本仓库的更新地址和签名配置。提供 macOS Universal、Windows x86_64、Linux x86_64 安装包；三平台构建成功后自动发布并核验发布资产。

## 验证

前端全量 2918 项、完整 Rust 3974 项测试通过；采集器测试 21 项（Python 与 Node.js 各一套，另有逐字节一致性对比）通过。新增 Rust 回归测试复现了原超时问题。TypeScript、生产前端构建、格式检查和 Clippy 通过。
