# CC Switch SSH v4.0.13-ssh.2

修复远端 Codex 压缩归档无法同步用量。

## 修复

- **服务器没有 `zstd` 命令也能读取 Codex 压缩归档。** 之前要求服务器装有 `zstd` 命令或 Python `zstandard` 模块，否则每个 `.jsonl.zst` 归档都报「compressed logs require zstd…」和「unreadable or invalid session file」。现在优先直接调用系统自带的 libzstd 库（Ubuntu、Debian、CentOS 等基础系统都自带），不需要安装任何东西。
- **超大单行记录不再导致整个文件读取失败。** Codex 会话里的上下文压缩快照、内嵌图片等记录可能超过 8 MiB，以前会让整个文件报错、断点无法前进。这类记录不含用量，现在直接跳过，文件里其他记录照常统计。
- 缺少解压工具时，提示只出现一次，不再为每个文件重复刷屏。

## 包含 v4.0.13-ssh.1 的全部内容

合并官方 4.0.12、4.0.13；修复远端用量同步总是超时；远端没有 Python 3 时改用 Node.js；远端页面分为「供应商」和「CLI 与用量」两个页签并新增返回按钮。详见 [v4.0.13-ssh.1 发布说明](v4.0.13-ssh.1-zh.md)。

## 验证

采集器测试 27 项（Python 与 Node.js 两套，含 libzstd 解码与超大记录用例）通过，Rust 远端用量测试、Clippy 通过。在一台没有 `zstd` 命令和 `zstandard` 模块的 Ubuntu 22.04 服务器上实测：392 个压缩归档全部可读，同步无错误。
