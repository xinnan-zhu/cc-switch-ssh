## CC Switch SSH v4.0.2-ssh.1

基于官方 **CC Switch 4.0.2 预览版**，保留 SSH 远端配置管理与反向隧道网关。

### 本次更新

- 修复通过 ChatGPT 账号使用 Claude Code 时，后续对话因思考记录字段被拒收而报 400 的问题。
- 修复 Codex 的模型映射和聚合模型被其他工具的模型目录指针挡住的问题。
- Claude 聚合模型改用 `modelPicker` 显示，减少重复模型条目，更新聚合模型后无需重启 Claude Code。
- 合入 Pi 1.0 MCP 同步、更新时间 MCP 预设、模型表单和图标等官方改进。
- 保留 SSH 配置推送、导入、进程管理、固定供应商和跟随本地路由；验证新版配置字段处理不会丢失远端登录及 Codex 路由 ID。
- 更新摘要兼容 SSH 构建版本号，升级后能显示对应官方版本的改动。
- 发布流水线自动附带详细说明，各平台构建成功后自动发布安装包和更新清单。

### 升级说明

- **数据库 schema 升至 20**。运行新版后回退 4.0.1 或旧版需要恢复迁移前数据库备份。升级前请保留 `~/.cc-switch/` 和客户端配置备份。
- **Claude 聚合模式要求 Claude Code 2.1.243 或以上**；远端使用该功能时也需检查远端 CLI 版本。
- macOS Universal 支持 Apple Silicon 和 Intel。安装包未做 Apple 开发者证书公证；如提示“已损坏”，可执行 `xattr -cr "/Applications/CC Switch.app"`。
- Windows 提供 MSI 和便携 ZIP，Linux 提供 AppImage、deb 和 rpm。更新地址继续跟随本仓库。

### 验证

前端全量 2176 项、更新摘要相关 23 项、后端全量 3369 项及 115 项集成测试通过，类型、格式、生产构建和 Clippy 检查通过。10 项后端测试按仓库设置跳过，真实 SSH 服务器反向隧道联调未运行。
