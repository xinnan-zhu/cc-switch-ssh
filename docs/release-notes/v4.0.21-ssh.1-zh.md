# CC Switch SSH v4.0.21-ssh.1

修复远端网关把所选 Codex 模型替换成默认模型的问题，并合并上游 **4.0.14–4.0.21** 的更新，共 306 个提交。现有 SSH 远端供应商管理、网关、CLI 更新和用量采集功能保留。

## 修复

- **远端选择 6.1 Sol 后，不再被网关改成 5.6 Terra。** 之前原生 Responses 请求中的模型如果不在供应商保存的模型列表里，网关会用供应商的默认模型覆盖。现在保留远端客户端实际选择的模型，普通请求和压缩请求行为一致；固定供应商和跟随本机供应商均适用。显式切换供应商时仍会推送新的远端配置，Chat／Anthropic 转换沿用原有模型映射。
- **远端更新继承服务器的代理与 npm 环境。** 更新命令在服务器的交互登录 shell 中执行，沿用其中导出的 HTTP／HTTPS／ALL_PROXY、NO_PROXY 和 npm 配置，避免版本检测正常但更新时无法联网。nvm／fnm 的临时环境会保留到更新结束。
- **修复识别为 npm 安装、更新时却找不到 npm 的问题。** CLI 启动入口是软链接时，优先从实际安装前缀寻找 npm，并把对应 Node 目录加入更新进程的 PATH；然后尝试启动入口旁的 npm 和登录环境中的 npm。确实未安装 npm 时给出明确提示。
- **远端用量筛选与新版统计页面保持一致。** 选择主机后，页签计数和按需展开的模型子菜单也按该主机查询。
- **兼容 SSH 版与上游的数据库升级。** 两个分支此前使用了相同的数据库版本号表示不同结构。本版补齐相应字段，保留历史用量、费用及远端来源，避免升级后遗漏数据或出现查询错误。

## 上游更新

本版合并至上游 `e55d8a21`，包括 v4.0.21 之后的 Windows 托盘点击修复。近期主要更新包括：

- Claude Code 多个官方订阅账号的切换，以及套餐和剩余额度显示。
- Codex 模型列表拖动排序、「打开终端」入口调整及轻量模式保持。
- 修复托管 ChatGPT 账号重启后误报登录过期、Codex 路由选错上游地址、Codex MCP 配置包含其他客户端字段等问题。
- 新版用量统计与更多客户端、模型预设的支持。

各版完整说明见 [本仓库发布说明目录](https://github.com/xinnan-zhu/cc-switch-ssh/tree/v4.0.21-ssh.1/docs/release-notes)；v4.0.21 详情见 [上游发布说明](https://github.com/farion1231/cc-switch/blob/v4.0.21/docs/release-notes/v4.0.21-zh.md)。

## 下载与升级

- **macOS Universal（Apple Silicon／Intel）**：下载 `.dmg` 或 `.zip`。
- **Windows x86_64**：下载 `.msi` 安装版或 `Windows-Portable.zip` 便携版。
- **Linux x86_64**：下载 `.AppImage`、`.deb` 或 `.rpm`。
- 应用内自动更新继续使用本仓库的更新地址与签名；`.tar.gz`、`.sig` 和 `latest.json` 用于自动更新，无需手动下载。

macOS 包采用临时签名，未做 Apple 公证。如首次打开提示「已损坏」，可执行 `xattr -cr "/Applications/CC Switch.app"` 后重试。Windows 包未做代码签名。
