## CC Switch SSH v4.0.3-ssh.1

基于官方 **CC Switch 4.0.3 预览版**，包含此前未单独发布的 4.0.2 更新，保留 SSH 远端供应商管理和反向隧道网关。

### 本次更新

- 合入官方 4.0.3：Claude auto mode 服务端检查开关、MCP/提示词整页编辑与未保存提醒、备份占用统计、OpenCode 2.0 配置、Codex Credits 余额及新增供应商预设。
- 修复映射模型的思考强度、混合 LF/CRLF 流式事件解析、Skill 导入后未部署、缓存 token 统计及用量写入阻塞等问题。
- 同时包含 4.0.2 的 ChatGPT 账号对话 400 修复、Codex 模型目录修复和 Claude 聚合模型选择改进。
- 保留 SSH 配置推送、导入、进程管理、反向隧道、固定供应商及跟随本地路由。远端请求仍按代理用量统计，本地退出路由时仍保持正在使用的远端网关。
- 验证 `CLAUDE_CODE_AUTO_MODE_SERVER` 可随供应商写入远端，同时保留远端设置、登录和 Codex 自有路由 ID。
- 更新摘要兼容 `-ssh.N` 构建号。发布工作流自动附带说明，并在发布后核验三平台安装包、latest 指向及更新清单。

### 下载与升级

- **macOS Universal**：DMG 或 ZIP，支持 Apple Silicon / Intel。
- **Windows x86_64**：MSI 或便携 ZIP。
- **Linux x86_64**：AppImage、deb 或 rpm。
- `.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新。更新地址与签名仍跟随本仓库。
- **从 v4.0.1-ssh.1 升级时，数据库 schema 由 19 升至 20**。升级前请保留 `~/.cc-switch/` 和客户端配置备份；回退 4.0.1 或更早版本需要恢复迁移前数据库备份。
- Claude 聚合模型选择要求 Claude Code 2.1.243 及以上；新的 auto mode 服务端检查相关功能针对 Claude Code 2.1.281 及以上。使用远端 CLI 时也应检查远端版本。
- macOS 包使用临时签名，未做 Apple 开发者证书公证；若提示“已损坏”，可执行 `xattr -cr "/Applications/CC Switch.app"`。Windows 包未做代码签名，安装时可能显示 SmartScreen 提示。

### 验证

前端 2249 项、后端 3412 项和 115 项集成测试通过，类型、格式、生产构建和 Clippy 检查通过。10 项后端测试按仓库设置跳过，真实 SSH 服务器反向隧道联调未运行。
