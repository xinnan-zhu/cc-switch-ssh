## CC Switch SSH v4.0.4-ssh.1

基于官方 **CC Switch 4.0.4 正式版**，新增 Grok Build 远端管理，继续支持 Claude Code、Codex 和 Gemini CLI。

### 本次更新

- 合入官方最新 `main`（与 `v4.0.4` 相同，`a29a4f38`）：修复 macOS 更新或修改配置目录后重启时窗口未置前的问题，修复窄窗口下用量表格速度列被挤出视野的问题。
- 项目切换器默认隐藏，可在设置中开启；关于页的 GitHub 邀请支持单独关闭。保留已有 SSH 入口和 fork 更新地址。
- **Grok Build 远端切换**：读取、导入和写入 `~/.grok/config.toml`，保留远端 MCP、界面设置和其他模型表。切回官方条目使用远端自身的 xAI 登录，不复制本机登录凭据。
- **Grok Build 反向隧道网关**：通过免密 SSH 使用本机第三方供应商，支持固定供应商或跟随本机路由，并保留聚合模型选择。退出网关时清理携带本机网关 token 的旧模型表。
- TOML 配置预览隐藏 API Key 和 token；无法解析时也不显示原始凭据。较长配置目录下 SSH 复用 socket 超出系统限制时，自动回退为独立连接。
- 进程操作文案改为「停止进程」：它会中断对应远端会话，需要手动重新打开客户端，不会自动启动进程。

### 下载与使用

- **macOS Universal**：DMG 或 ZIP，支持 Apple Silicon / Intel。
- **Windows x86_64**：MSI 或便携 ZIP。
- **Linux x86_64**：AppImage、deb 或 rpm。
- `.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，更新只跟随本仓库。
- 从 `v4.0.3-ssh.1` 升级，数据库 schema 仍为 20。从 4.0.1 或更早版本升级仍涉及数据库迁移；回退需使用迁移前备份。
- Grok 供应商使用 `env_key` 时，直连模式需要在远端设置对应环境变量。网关模式不支持转发本机官方订阅登录；本机与 CC Switch 必须保持在线。
- 配置写入没有远端自动备份。macOS 包使用临时签名，未做 Apple 开发者证书公证；如提示“已损坏”，可执行 `xattr -cr "/Applications/CC Switch.app"`。Windows 包未做代码签名。
