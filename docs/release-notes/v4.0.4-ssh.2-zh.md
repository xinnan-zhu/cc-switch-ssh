## CC Switch SSH v4.0.4-ssh.2

基于官方 **CC Switch 4.0.4** 及其后的 `main`，修复远端网关的授权与配置同步问题，继续支持 Claude Code、Codex、Gemini CLI 和 Grok Build。

### 本次更新

- **合入官方最新 `main`（`5ae6ad38`）**：Codex 支持 GitHub Copilot 托管账号（Responses/Chat 路由）；Claude Code npm 安装可启用原生安装；Linux 安装包支持应用内自动更新；Grok Build 会话用量导入从 10 分钟缩短到 60 秒；用户手册和 README 更新到 4.0。
- **远端网关按应用授权**：主机网关 token 只证明是哪台主机，每个应用还需要单独启用的路由。同一主机上关闭某个应用后，持有 token 的客户端无法再访问它，也不会退回使用本机当前供应商的凭据；从未启用的应用、固定供应商已被删除的路由同样拒绝。远端 CLI 用不到的路径返回 404。
- **修改隧道端口时同步全部应用**：同一主机的多个应用共用一个端口。在任一应用页面改端口，会把该主机所有已启用应用的远端配置一起指向新端口；任一步失败都会恢复旧端口、旧隧道和已改过的远端配置。
- **Gemini 网关切换供应商后使用新模型**：远端 Gemini CLI 请求 URL 中的模型名，会按当前路由供应商的模型改写。固定供应商和跟随本机两种模式都在下一次请求生效，无需重写远端文件或重启。
- **配置预览遮罩 TOML 内凭据**：Codex 和 Grok Build 的 `config.toml` 逐键遮罩 `experimental_bearer_token`、`api_key`、认证头等字段；无法解析时整段隐藏。

### 下载与使用

- **macOS Universal**：DMG 或 ZIP，支持 Apple Silicon / Intel。
- **Windows x86_64**：MSI 或便携 ZIP。
- **Linux x86_64**：AppImage、deb 或 rpm。
- `.tar.gz`、`.sig` 和 `latest.json` 用于应用内更新，更新只跟随本仓库。
- 从 `v4.0.4-ssh.1` 升级，数据库 schema 仍为 20，无需迁移。已启用的网关路由和 token 保持不变。
- 升级后，远端已关闭的应用即使带着旧 token 也会收到 403。需要用的应用请在 CC Switch 中重新启用网关。
- 网关模式不支持转发本机官方订阅登录；本机与 CC Switch 必须保持在线。配置写入没有远端自动备份。macOS 包使用临时签名，未做 Apple 公证；如提示“已损坏”，可执行 `xattr -cr "/Applications/CC Switch.app"`。Windows 包未做代码签名。
