## CC Switch SSH v4.0.4-ssh.3

修复通过 SSH 切换远端 Codex 配置后 `auth.json` 消失、认证失效的问题。基于 `v4.0.4-ssh.2`，保留该版本的网关授权、共享端口迁移、Gemini 模型和凭据预览修复。

### 本次修复

- **远端 API Key 认证**：不再删除只包含 API Key 的 `~/.codex/auth.json`；切换时将所选供应商的新 Key 同步到认证文件及活动供应商表，并设置对应认证标志。远端文件已缺失时会重新创建，连续切换不会继续使用旧 Key。
- **网关认证**：认证文件和活动供应商表写入相同的主机网关 token，不把本机供应商的上游 Key 复制到远端。
- **保留远端登录**：已有 OAuth 等登录凭据保持不变；环境变量、认证头或无 Key 的路由不会使用保留下来的旧 Key 作为回退认证。认证文件格式损坏时拒绝覆盖，提示先修复。
- **官方 API Key**：切到明确配置了 OpenAI API Key 的官方供应商时，同步更新远端认证文件。

### 升级后操作

升级后，请在远端 Codex 页面重新切换一次供应商；若旧版本已删除 API Key 认证文件，本次切换会按所选供应商重新创建。网关用户重新应用网关配置。无需迁移数据库。

### 验证

完整 Rust 测试集 3669 项通过（17 个测试目标，单线程），11 项按设置跳过；其中新增的原生 Codex 测试单独运行通过，使用本机 Codex CLI 0.160.1 和隔离配置目录验证 API Key 认证文件可被识别。实际 shell 写入和读取脚本覆盖认证文件重建及连续切换。

Rust 格式检查、全部 targets 的 Clippy（零警告）及差异检查通过。未在用户真实远端运行模型请求。
