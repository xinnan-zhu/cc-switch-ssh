# CC Switch SSH v4.0.42-ssh.2

合并上游 **4.0.22–4.0.42** 的更新，共 **651 个提交**，保留 SSH 远端供应商管理、反向隧道网关、远端 CLI 更新和用量采集。本版合并至上游 `de1405016`，包含 v4.0.42 发布后的工具环境、用量速度统计和账号状态修复。

## 上游主要更新

- **更多客户端**：新增 DeepSeek Harness、GitHub Copilot CLI、WorkBuddy 和 CodeBuddy 支持，以及 Copilot CLI 到 VS Code Copilot 插件的同步。
- **GitHub Copilot Auto**：Claude、Codex 和 Claude Desktop 可以使用 Copilot 自动选模型，支持的 Free 账号也可使用。
- **会话与用量**：会话正文搜索、新版 Codex 会话分组、Codex `/goal` 完整目标显示、更多客户端的用量导入、缓存命中率、汇率获取和模型定价更新。
- **技能与插件**：插件管理页面，技能仓库支持私有仓库及 GitLab、Gitea、Forgejo，MCP 连通性检查。
- **账号与界面**：更多官方账号的订阅、余额和额度显示，Codex 官方额度保护、隐私过滤器、后台自动下载更新、界面密度和缩放调整。
- **稳定性修复**：修复跨应用显示 Antigravity 账号、账号切换绑定、Unix 工具环境继承和用量速度计算等问题。

各版完整说明见 [发布说明目录](https://github.com/xinnan-zhu/cc-switch-ssh/tree/v4.0.42-ssh.2/docs/release-notes)，4.0.42 详情见 [上游发布说明](https://github.com/farion1231/cc-switch/blob/v4.0.42/docs/release-notes/v4.0.42-zh.md)。

## SSH 版兼容处理

- **Linux RPM 打包**：修复新版打包工具拒绝 SSH 版本号的问题。RPM 使用符合系统规范的包版本，应用内仍显示完整 SSH 版本，后续升级顺序保持正常。

- **远端配置和网关**：适配上游新版供应商接口及 Claude 配置生成逻辑。远端连接页面使用新版页签组件，固定供应商、跟随本机和反向隧道功能保留。
- **远端模型选择**：继续保留客户端选择的 Codex 模型，避免将目录外的模型替换为供应商默认模型；Gemini 路由切换和 Grok Stack 模型处理继续保留。
- **远端更新**：沿用服务器交互登录环境中的代理、npm 注册表和 Node 环境，并复用上游最新工具安装参数与版本通道逻辑。
- **按主机统计**：将主机筛选接入新版统一统计查询，明细、汇总、图表和模型选项仍按所选主机查询。远端网关的实测速度与会话日志的估算速度分开统计，并采用上游新增的状态码和速度上限校验。
- **旧版数据库升级**：兼容 SSH 版与上游曾重复使用的数据库版本号，补齐新客户端开关和会话游标字段，保留历史费用、请求数及远端来源。

## 下载与升级

- **macOS Universal（Apple Silicon／Intel）**：下载 `.dmg` 或 `.zip`。
- **Windows x86_64**：下载 `.msi` 安装版或 `Windows-Portable.zip` 便携版。
- **Linux x86_64**：下载 `.AppImage`、`.deb` 或 `.rpm`。
- 支持应用内更新的安装方式继续使用本仓库的更新地址与签名；`.tar.gz`、`.sig` 和 `latest.json` 用于自动更新，无需手动下载。

macOS 包采用临时签名，未做 Apple 公证。如首次打开提示「已损坏」，可执行 `xattr -cr "/Applications/CC Switch.app"` 后重试。Windows 包未做代码签名。
