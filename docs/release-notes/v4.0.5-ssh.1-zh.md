## CC Switch SSH v4.0.5-ssh.1

合入官方稳定版 **CC Switch 4.0.5**，同时修复 SSH 切换远端 Codex 后 `auth.json` 消失、认证失效的问题。支持 Claude Code、Codex、Gemini CLI 和 Grok Build 的远端配置切换与网关。

### 官方更新

- 「全部」用量热力图支持每 53 周一段向前展开，一直查看到最早的记录。
- 修复 Claude Code 经 Responses 协议映射到 GPT 后，可选工具参数被当成必填、子代理总被派到 worktree 的问题。
- 修复 Codex 聚合模型继承隐藏模板，导致 GLM 等模型在 `/model` 中消失；模力方舟预设补全 5 个模型的目录及能力。
- 修复 Linux Wayland 的标题栏按钮失效，以及 Windows MSI 升级后固定图标变空白的问题。
- 保留官方 GitHub Copilot 托管账号及 Linux deb/rpm 应用内更新支持；更新签名全部存在且非空才允许发布。

### 远端 Codex 认证修复

- API Key 模式不再删除 `~/.codex/auth.json`，切换时同步更新认证文件及活动供应商表，缺失时重新创建。
- 网关模式使用主机网关 token，不把本机上游供应商的 Key 复制到远端。
- 保留远端已有 OAuth 等登录凭据；格式损坏的认证文件拒绝覆盖，提示先修复。
- 环境变量、认证头及无 Key 路由不会使用旧认证文件中的 API Key 作为回退来源。
- 继续保留此前的网关按应用授权、共享隧道端口迁移、Gemini 模型切换及 TOML 预览脱敏修复。

### 升级与下载

- **升级后请重新切换一次远端 Codex 供应商，或重新应用网关配置**，以重建旧版本删除的 API Key 认证文件。
- 数据库 schema 仍为 20，无需迁移；应用内更新继续跟随本仓库。
- 提供 macOS Universal、Windows x86_64、Linux x86_64 安装包。三平台全部构建成功后自动发布，并核验 14 个资产及 6 个更新平台。
- Linux deb/rpm 用户若旧版更新仍提示权限不足，请手动安装本版，此后可正常应用内更新。Windows 已固定的图标若仍空白，取消固定再重新固定即可。
- `v4.0.4-ssh.3` 的发行流程已取消，认证修复包含在本版。官方 PR #7918 已按用户要求关闭。

### 验证

前端 198 个文件、2322 项测试通过；完整 Rust 测试集 17 个目标、3672 项通过（单线程，11 项按设置跳过）。原生 Codex CLI 0.160.1 的隔离认证验证单独通过，类型、格式及前端生产构建检查通过。发布前签名检查已验证完整签名可生成更新清单，15 个缺失、空白或空签名场景均被拒绝。

全部 targets 的 Clippy 检查通过，无警告。本机为 macOS，未在用户真实远端运行模型请求。
