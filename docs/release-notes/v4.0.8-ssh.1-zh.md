## CC Switch SSH v4.0.8-ssh.1

合入官方稳定版 **CC Switch 4.0.8**（包含 4.0.6、4.0.7、4.0.8 三个修复版本），并在 SSH 远端页新增**一键更新远端 CLI**。支持 Claude Code、Codex、Gemini CLI 和 Grok Build 的远端配置切换、网关和版本更新。

### 远端 CLI 一键更新

- 连接 SSH 服务器后，远端页在连接区下方新增「远端 CLI 版本」卡片，列出服务器上 Claude Code、Codex、Gemini CLI 和 Grok Build 的当前版本与最新版本，当前应用排在第一行。
- 有新版本时显示「更新」按钮；多个可更新时可「全部更新」，逐个执行，避免同时运行的 npm 安装互相冲突。更新当前应用的 CLI 后，提示里可以直接「停止进程」，让已运行的 CLI 换上新版本。
- 按原安装方式更新：npm 全局安装使用二进制旁边的 npm（nvm、fnm 等多版本 Node 不会装到别的 Node 上）；Claude Code、Grok Build 官方安装使用自带的 `update`；Homebrew 安装使用 `brew upgrade`。无法识别安装方式时显示「需手动更新」，不会另装一份。
- SSH 非交互会话不加载 `.bashrc`/`.zshrc`，检测时会读取登录 shell 的 PATH 并补充常用的用户级安装目录，所以通过 nvm、fnm 安装的 CLI 也能找到。
- 更新失败时显示退出码和最后几行输出；远端 npm 全局目录需要管理员权限时会提示改用 sudo 或用户级 Node。单次更新最长 15 分钟。

### 官方更新

- Codex 聚合模式：只装 Codex 桌面版也能使用；官方模型列表读不到时写明原因，恢复后提示自动消失；可选经典子代理工具，修复子代理读不到任务。
- 同一 OpenAI 账号下 Plus、Team 工作区可以正常切换；Codex 历史会话支持压缩，会话管理和用量统计能读取压缩后的会话。
- 额度可显示「已用」，恢复绿、橙、红三色；修复 Claude 1 小时缓存写入价格、部分中转站缓存命中等用量统计问题。
- 供应商页新增搜索按钮；Skills 支持一键全部更新；「设置 → 数据」新增「打开日志」；深色模式文字调暗。

### 升级与下载

- 数据库 schema 仍为 20，无需迁移；应用内更新继续跟随本仓库。
- 远端 CLI 更新在服务器上运行，不修改远端配置文件；网关、远端切换及此前的 Codex 认证修复保持不变。
- 提供 macOS Universal、Windows x86_64、Linux x86_64 安装包。三平台全部构建成功后自动发布，并核验 14 个资产及 6 个更新平台。

### 验证

前端 205 个文件、2450 项测试通过；完整 Rust 测试集 17 个目标、3767 项通过（单线程，11 项按设置跳过）。远端检测与更新脚本在本机 `sh` 下用模拟的 npm、官方安装和缺失 CLI 实际运行验证，并在本机最小 PATH 下正确识别了官方安装的 Claude Code、Grok Build 及经 fnm 安装的 Codex。

全部 targets 的 Clippy 检查通过，无警告；类型、格式及前端生产构建检查通过。本机为 macOS，未在用户真实远端服务器上执行更新。
