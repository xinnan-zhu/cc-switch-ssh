## 实现

- `provider/remote_usage.rs`：配置、限时 SSH 调用、原子提交、永久消息账本、每主机同步互斥；自动同步每 300 秒运行，失败保留旧断点并记录错误。
- `provider/remote_usage_collector.py`：只读元数据采集；按文件读取增量、验证已读尾部、处理不完整末行、改写和归档。Codex 优先使用单请求 last_token_usage；没有单请求值时取累计计数差，保留跨模型和速率桶的基线及重复快照标记。Claude 同消息 ID 的最终分块可补全用量，Gemini 合并 thoughts 到输出，Grok 读取每个 prompt 的 turn_completed。
- 默认日志目录：Claude `~/.claude/projects`；Codex `$CODEX_HOME/{sessions,archived_sessions}` 或 `~/.codex`；Gemini `~/.gemini/tmp`；Grok `~/.grok/{sessions,archived_sessions}`。自定义目录可按应用覆盖，每行一个目录。
- 数据库增加远端同步设置、文件游标、网关消息 ID 和网关记账时段；会话去重沿用永久 `session_usage_dedup`。明细 `remote_session:<host>:<app>` 与网关 `remote:<host>` 分开分类；查询按 host origin 同时筛选两类来源。
- schema 20 → 21 重建日汇总主键，纳入 data_source。旧版汇总标记 legacy，保留数值，避免猜测来源。WebDAV/S3 同步跳过并保留本机远端采集表。
- 客户端缺少响应 ID 时，启用网关的同主机／应用时段只由网关记账；无法识别这期间绕过网关的独立请求。压缩 Codex 文件在远端解压，需要 zstd 命令或 Python zstandard；不传回原始内容。未提供可验证计时的会话记录速度为未知。
