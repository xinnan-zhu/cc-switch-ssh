# CC Switch SSH 升级到 4.0.3

## 合并范围

- 上次已验证的升级提交：`04b4dfc3`，官方基线为 `v4.0.2`。
- 此次合入官方发布标签 `v4.0.3`，提交 `8596a233`，保留共同历史。
- 升级分支：`codex/upgrade-4.0.3-ssh`；发布标签：`v4.0.3-ssh.1`。
- 官方 `main` 在检查时另有一个 Hermes 测试夹具事务优化提交 `d35726e2`，不影响产品行为，此次发布使用已发布标签。

官方版本仍为预览版。4.0.3 相对 4.0.2 修复了流式事件混合换行、映射模型思考强度、用量写入阻塞和 Skill 部署等实际使用问题，适合继续合并。此次发布也包含此前没有创建 release 的 4.0.2 升级。

## 适配

- 合并唯一冲突位于 `tests/integration/App.test.tsx`，保留 SSH 页面导航测试和官方未保存编辑提醒测试。
- SSH 模块继续使用新版配置补丁，验证新增的 Claude auto mode 字段会写入远端并保留远端用户设置。
- 固定远端路由、聚合模型限制、共享代理生命周期、远端用量来源和云同步令牌保留逻辑继续保留。
- 保留 fork 更新地址、签名公钥、SSH 构建版本的更新摘要适配及独立发布工作流。

## 自动发布

推送 SSH 标签触发三平台构建。构建成功后，Actions 自动生成更新清单、上传安装包并读取对应的中文说明。

新增发布后核验步骤：读取实际 release 和 latest 状态，下载已发布的更新清单及签名，核验 12 个资产上传完整、四个平台的 URL 和签名匹配、中文说明与提交文件一致。该步骤在发布事件流程内执行，不依赖聊天循环查询进度。

核验脚本已用现有 `v4.0.1-ssh.1` 发布数据验证，并确认错误的更新 URL 和签名会被拒绝。

## 升级限制

数据库 schema 仍为 20；相对公开的 `v4.0.1-ssh.1`（schema 19）需要迁移。运行新版后回退 4.0.1 或更早版本应恢复迁移前数据库备份。

此次工作不安装覆盖本机应用。真实 SSH 服务器反向隧道联调仍未运行。
