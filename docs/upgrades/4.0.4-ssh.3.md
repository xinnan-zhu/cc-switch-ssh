## 实现

- 本地写入仍沿用官方行为；远端在活动路由的 bearer key 确定后，单独计划 `auth.json`，不生成删除认证文件的写入。
- 远端没有 OAuth 等凭据时，将 API Key 同时写入 `auth.json` 和活动供应商表；认证文件缺失时创建；保留自定义路由 ID、MCP 和其他主机配置，文件权限为 0600。
- 网关先用主机 token 替换代理占位凭据，再计划认证文件，避免把本机上游 Key 或占位 Key 复制到远端。
- 已有真实登录凭据时不改认证文件。环境变量、认证头、无 Key 的第三方路由不把旧认证文件中的 API Key 作为回退来源。
- 格式损坏或非对象认证文件不能确认是否含有登录，不覆盖，整个写入计划报错。
- 官方供应商明确提供 API Key 时更新认证文件；空官方认证配置仍保留远端登录。
