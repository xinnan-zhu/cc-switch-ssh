# CC Switch SSH 升级到 4.0.4

## 合并范围

- 已发布基线：`a585a590` / `v4.0.3-ssh.1`。
- Grok Build 远端支持：`81c8158a`，来自 `codex/ssh-grok-remote`。
- 合入官方最新 `main`：`a29a4f38`，与官方 `v4.0.4` 标签一致。
- 升级分支：`codex/upgrade-4.0.4-ssh`；发布标签：`v4.0.4-ssh.1`。

  4.0.4 是官方 4.0 的首个正式版。相对已合入的 4.0.3，新增 macOS 重启经 LaunchServices 置前、窄窗口用量速度列修复、项目切换器默认隐藏、关于页 GitHub 邀请独立关闭，以及 Hermes 测试夹具事务优化。此次直接合并 `main`，没有丢弃 fork 历史。

## SSH 适配

合并无冲突。保留现有 Claude Code、Codex 和 Gemini CLI 远端功能，新增 Grok Build 的配置读取、导入、直接切换、进程停止和反向隧道网关。

- Grok 只修改 `~/.grok/config.toml` 的托管模型表和默认选择，保留远端用户模型及 MCP；不读取或复制 xAI 登录文件。
- Grok 网关使用 `/grokbuild/v1`，固定供应商及跟随本地路由继续使用共享网关机制。已解析的聚合模型不会被供应商默认模型覆盖。
- 退出 Grok 网关时，仅清理已匹配供应商的模型表和携带已知本机网关 token 的模型表。
- TOML 配置预览对 API Key 和 token 遮罩，解析失败时隐藏原文。
- 纳入此前真实 SSH 验证发现的 socket 路径长度修复：路径过长或含空白时禁用复用，使用独立连接。
- 「重启进程」改为「停止进程」，准确说明需要用户重新打开客户端。
- 保留 fork 更新地址、公钥、独立发布工作流和 SSH 构建号的更新摘要映射，并在 4.0.4 摘要中补充 Grok 功能。

## 发布流程

源码使用官方版本号 `4.0.4`。推送 `v4.0.4-ssh.1` 时，Actions 为 Tauri 生成完整版本号 `4.0.4-ssh.1`，Windows MSI 使用 `4.0.4.1`。

macOS Universal、Windows x86_64、Linux x86_64 三平台构建全部成功后，依赖事件触发发布 job，自动生成 `latest.json`、公开 release、上传 12 个资产并核验实际下载 URL、签名、latest 指向和中文说明。无需聊天循环查询构建进度。

## 升级边界

数据库 schema 仍为 20，从 4.0.3 升级没有新增 schema 迁移。Grok 的 `env_key` 在直连时依赖远端环境变量，网关不转发本机官方订阅登录。配置写入没有远端自动备份或多文件回滚；远端命令没有整体执行超时。此次不会覆盖安装本机应用。

自动化测试覆盖 Grok 配置保留、官方态识别、网关凭据与路由、进程筛选、聚合模型保留及 UI 凭据遮罩；原生 Windows SSH/ASKPASS 和完整 Grok CLI 交互尚未在本机实测。

## 验证结果

- 前端全量：194 个文件、2254 项测试通过。
- 完整 Rust 测试集：3605 项通过、10 项按仓库设置跳过，包含所有集成目标；以单线程运行，隔离真实用户配置。
- 真实 SSH 反向隧道测试单独启用并通过，验证正确 token、错误 token 及关闭路径。
- TypeScript、前端格式、Rust 格式、生产前端构建和全 targets Clippy（警告视为错误）通过。
- 官方版本号统一为 4.0.4，fork 更新地址和签名公钥与上个发行版一致。现有官方 PR 分支仍为 `f7dea080`，没有更新。
