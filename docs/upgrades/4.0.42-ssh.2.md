## RPM packaging compatibility

The updated Tauri CLI rejects hyphens in RPM Version. Compile the Linux application and AppImage/deb packages with the full SSH version, then use standalone `tauri bundle` to generate RPM metadata with numeric Version `4.0.42` and Release `1.ssh.2`. Standalone bundling does not recompile the executable, so its application version remains `4.0.42-ssh.2`. Assert the RPM metadata before upload; sign the final RPM as usual. The initial `v4.0.42-ssh.1` build did not publish a Release; keep its existing tag and publish this correction under a fresh tag.
