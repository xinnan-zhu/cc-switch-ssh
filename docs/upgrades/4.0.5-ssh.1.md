## 远端认证

修复原因见 [认证修复记录](4.0.4-ssh.3.md)。API Key 模式同步更新或创建认证文件，OAuth 等登录保持不变；网关先确定主机 token，再将它同步到配置和认证文件。用户升级后需要重新应用远端配置。
